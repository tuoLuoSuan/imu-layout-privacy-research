# 攻击条件与防护：现有证据支持到哪里

本页是既有模拟的输入条件分析，不是已部署防御评测。没有训练新模型、修改手机/手表采集器或增加硬件。

## 哪些信息缺失，并不会让攻击直接失效

| 攻击者缺少的信息 / 操作 | 当前依据 | 能支持的结论 |
| --- | --- | --- |
| 房间绝对原点 | 距离谱只依赖点对距离；共同平移控制与无噪声逐项相同 | 仅删除绝对位置或统一平移不阻断此类匹配 |
| 起点朝向 | 旋转与反射保留点对距离 | 未知朝向仍可存在布局身份信息 |
| 统一尺度 | 本评分器用距离均方根归一化 | 仅统一缩放坐标不改变归一化距离谱；其它尺度已知/未知的评分器不能混报 |
| 动作类别标签 | 当前自动分组衔接只读坐标，不读取粗类 | 删除标签不等同删除几何信息 |
| 手表输入 | 现有手机单端动作和轨迹产物仍保留 | 不能将“禁用手表”描述为完整阻断；腕部在不同批次的增益不一致 |

## 同一标称误差档，进入几何匹配器的影响不同

下列四行均为已有六类库、600测试房×4路线、32次给定事件、正确分组、未知尺度的子集归一化距离谱，lambda=0。它们**不是**网页主表lambda=.0003的自动分组结果。

| 冻结坐标条件 | 身份top-1 |
| --- | ---: |
| 无噪声 | 77.560786% |
| σ=.5m，共同平移 | 77.560786% |
| σ=.5m，随机游走 | 42.334888% |
| σ=.5m，独立误差 | 5.230721% |

σ是模型参数，不是实测设备误差RMS，三个结构也不是同一条物理误差轴。共同平移被差分抵消；原评分程序直接复用无噪声分数。这是数学不变性控制，不是另一轮独立实验，不作第二条独立证据。独立误差更容易扭曲距离谱。这是几何机制的输入条件证据，不能直接称“给真实IMU加噪能防住攻击”。对原始IMU施加什么处理、能否诱导类似误差、正常活动识别与导航会损失多少，均未测。

## 更值得测试的候选措施

1. 在数据访问层限制长时间、连续的后台惯性记录和跨会话关联，减少可积累的独立地点与回访关系；不把一次权限开关当已验证防护。
2. 若设计扰动，要检查扰动是否真的改变跨地点相对几何；统一平移/旋转/缩放与逐段不一致扰动不是同一种处理。
3. 限制环境候选先验及可用于定位的附加锚；当前结果依赖已知闭600候选库。没有这个库时真实排名尚未评测，但攻击者仍可能推断相对关系，不能写成完全无信息。
4. 将隐私效果与正常使用代价同时测量：攻击身份得分、回访召回、正常动作识别、正常导航/能耗等。当前没有证据支持某个已部署防护的收益—代价点。

优先级应由新的独立开发/测试协议决定，不拿已见过的测试成绩倒推一档恰好“防住”的噪声。

网页新增39个坐标输入条件×9队列，共351行。给定正确分组、闭600候选、lambda=0的未知尺度距离谱；与lambda=.0003自动分组主表分开。数值来自冻结产物，此处不重算匹配分数；本轮从保存的逐查询分数独立重汇总top-1/top-5/top-10，最大差小于8e-16，并对汇总重算整房区间。两遍输出逐字节相同，不代表匹配器从头重放。

## 不新增采集时的收尾边界

本线可完成合成坐标条件下的隐私敏感性与攻击失效分析。真实IMU端到端排名、跨端物理时间桥、真实候选房屋以及部署防护的正常功能代价维持未验证；它们限制结论范围，不作为用户继续采集的待办。

优先考虑在可信系统层限制不必要的连续原始惯性读取、在设备内处理后仅共享必要结果，并控制持久保存与跨会话关联。这些措施只有在攻击者不能绕过接口自行读取原始信号时才切断相应输入路径；动作结果本身仍可泄露语义。没有候选库时不能报当前闭集身份排名，但相对空间关系也不能据此宣称安全。

当前队列仅用于分层评价，不把房型或同形标签提供给攻击者，候选始终为600。固定算法得分若低于全库均匀猜测1/600=0.17%，不意味着理性攻击者的最佳成绩也低于该地板；这些结果不是所有攻击者的上界。
