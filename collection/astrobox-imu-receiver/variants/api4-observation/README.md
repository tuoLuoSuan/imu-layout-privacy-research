沿用SDK0.4.0、API4/WASI3、原生async、插件名称与received缓存、device/register_interconnect_recv/interconnect三权限。生成覆盖层从保留的0.2.0宿主源构造新宿主：增加四个处理次数和最近阶段，处理前立即显示，回复调用失败不再静默。原消息解包规则、shared receiver/UI状态、CRC／同步保存／顺序与冲突门不改。手表、手机采集App、旧包与原记录不改。

计数分别为：消息进入插件、识别S5TX1包、保存通过、回复提交。含重发，不是唯一分片或样本数；回复提交只说明AstroBox宿主API返回成功，不证明手表收到。忽略的消息会计数，日志保留受控形状类别；不打印原始消息、XYZ、会话标识、地址或账号／配对字段。
