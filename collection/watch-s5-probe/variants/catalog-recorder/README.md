# S5记录页按需读取 / 0.4.4

继承0.4.3的前台保亮和普通加速度入口；本版只优化记录摘要读取，原采集/运输/取消/删除实现保留。

打开列表列一次目录，仅选择某条时读取head/tail，不读样本块。最多缓存8份界面摘要；创建/回收/恢复/永久删除会话时失效。导出及所有删除操作仍重新查询原文件，缓存不是备份凭证。

旧记录不迁移、不自动删除。回收区可恢复，但仍占手表空间；永久删除继续要求确认且禁止删除未封口记录。保留40条会话上限，接近上限时应先核验外部导出，再由用户整理。

测试中的I/O次数下降不等于真机毫秒提速。0.4.3的high49/mid83/high166三条实际原件保留：首次high约5次/秒，后一次约16.71次/秒，原因未定；不把列表优化当频率修复或长时间采集验收。
