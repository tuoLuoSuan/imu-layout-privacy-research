# S5 0.3.4：目录URI兼容修正候选

0.3.3真机照片显示file.list返回20项，首个旧文件URI使用`internal://files//…`。旧核心只剥掉`internal://files/`，留下前导斜杠，使严格的会话文件名筛选漏掉这类条目。照片未直接显示v2头文件和99条正文，具体记录恢复仍待真机。

本版独立继承0.3.3暂存，在目录枚举边界接入`directory-entries.js`：接受本目录bare文件名、标准URI及本机观察到的一条额外根分隔符，去重后再交原有list/inventory/容量/回收/删除流程。不任意截取basename；其它目录、嵌套路径、穿越、反斜杠、编码分隔符和多于观察到的斜杠均拒绝。异常列表形状显式报错。

不会重命名、迁移、重写或补录旧文件。原记录metadata保持原版本，只有以后新录的app_version为0.3.4。既有读删allowedName门仍在。普通三功能、签名、圆标、导出协议和0.3.3原始文件检查页保留；诊断页仍展示原始URI。

```text
node --test collection/watch-s5-probe/tests/*.test.cjs
node collection/watch-s5-probe/tools/build_directory_uri_fix_source.cjs
```

回归先以观察到的双斜杠格式复现旧核心：合成已封口99条仍列0条；新核心列出并读回99条、全部原文件字节不变。另验混合别名去重、恶意路径、40条容量门及指定会话回收/恢复/删除。软件验证不冒充手表原件已恢复。

构建到不存在的dist/directory-uri-fix-0.3.4，拒绝覆盖旧输出。正式候选文件与SHA见首次真机协议顶部。用户保留数据覆盖升级后只查看已有记录，不重录/删除；确认列表后，再走手机已准备的普通传输。分钟/息屏/数据单位/真正出口仍待分级验证。
