# 手表 0.3.1：普通消息传输工作副本

新增“记录→导出→蓝牙传输”，与[AstroBox接收插件](../../../astrobox-imu-receiver/README.md)配合，接收后一次保存TXT到手机/电脑，再独立核验。新版本保留备用二维码和旧版最近记录只读恢复；不使用任意文件读取、root、固件改造或高权限模块。

实际实现代码在本profile，构建先复制0.3.0再覆盖页面/发送模块，只在临时区改0.3.1/code5、采集metadata版本与 `system.interconnect` 声明。0.3.0采集核心/文件格式/停止与存储逻辑不改；手机66文件、旧手表源和包不改。用户已报告0.3.0首页正常，0.3.1本轮尚未上表。

发送只由用户点击触发，禁止传输时采新数据/切记录；系统send成功不当落盘成功，匹配应用层ACK才推进。断线/无确认/文件错误有明确提示，重试复用已接收段；退出传输页面会取消，原记录保留。当前先保持页面前台，不承诺息屏传输。

构建（沿用现有本地签名/工具链；缺签名明确失败）：

```text
node collection/watch-s5-probe/tools/build_transfer_source.cjs
```

输出默认 `dist/transfer-0.3.1`，已存在则拒绝覆盖。可传模块dist内的新目录保留多个候选。JSC=false、Protobuf=false；实际归档/签名需另核，不靠构建成功推断机型兼容。

先安装并检查手机接收插件，再保留数据覆盖升级手表0.3.1，只传既有2秒记录。链路和原件核验后再测新版功能，最后合并DS交接；不把未运行蓝牙或未收到原件写成通过。
