# S5统一科研界面 0.2.0/code3

用户选择A（浅灰底、白卡片、青色按钮、采集/记录两页），并明确要求手表图标与手机一致。本目录是UI替换profile，构建时复用模块原src的采集核心；不是可独立直接运行aiot build的完整工程。原0.1.1、旧失败包和原src保留。

界面只整理现有三轴、设置、恢复最近一条、保存重试和二维码导出。没有增加陀螺仪、按Hz请求、完整历史列表/删除或无线传输。切到记录页不能绕过采集/保存/读取中的状态门；旧会话导出保留它原来的版本与数值，不改成新版数据。

## 构建和核验范围

在watch-s5-probe目录运行`node tools/build_ui_source.cjs`，输出`dist/ui-0.2.0/org.imuresearch.s5probe.release.0.2.0.rpk`，已有输出拒绝覆盖。工具链/签名准备沿用模块README。临时quickapp配置与显式编译参数均关闭JSC/Protobuf，不运行旧两个构建脚本替代本入口。manifest和新会话metadata均为0.2.0/code3；capability仍只有sensor/file。

本机生成16978字节，SHA-256 `27678610cf9521f7fb73b045ab0235828853961566c34b1f1dbe1f63c5848e5d`。实际CRC、外层RSA/签名内容摘要、版本、源码格式、归档图标已核；25Node/6Python通过。真实Chrome中查看了四页布局及合成保存失败提示，不等于Vela真机渲染。0.2.0尚未安装/运行在S5，不能继承0.1.1的用户反馈。

## 同源图标与布局预览

图标来自手机原始`app/src/main/res/drawable/ic_app.xml`，保留路径、填充、描边和圆角。`python tools/export_phone_icon.py variants/research-ui/icon.svg`生成同源SVG，再用浏览器渲染为192×192透明PNG。渲染器版本可能影响PNG抗锯齿与字节，不承诺跨浏览器逐哈希复现；矢量几何和颜色可直接审查，实际PNG已固定摘要纳入源码白名单。手机矢量原件未改。

`node tools/preview_ui.cjs dist/ui-preview.html`生成使用实际UX模板/样式和此PNG的独立浏览器布局预览。页面明确标“非手表实测”，开始/停止/文件操作不会访问设备；二维码只是区域示意。浏览器预览不替代Vela运行时与真实数据验收。

## 为什么现在只有短录

2/10/30秒与2000回调上限来自首版入口短试设计，**不是实测硬件时长或存储容量上限**。当前核心把会话留在内存，停止后写完整JSON，二维码导出还会序列化/分片；长期采集需要单独设计分批落盘、受控缓冲和可靠出口，再实测隐藏/熄屏、功耗与持续性。没有查询S5可用内存/磁盘，也没有分钟级真机结果。此UI改版保持这些限制，不因改外观悄悄扩大采集范围。
