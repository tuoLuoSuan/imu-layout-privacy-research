# S5最小启动检查0.0.1

用户报告采集包0.1.0打开后黑屏，整只表暂时不响应后恢复。该现象尚无设备运行日志，不能归因于传感器、二维码、固件或任何单独函数；0.1.0暂停真机使用，已有17项软件测试不当作启动通过。

本目录为独立包org.imuresearch.s5start，手表名“S5 启动检查”，不覆盖原采集包、不采数据。只使用div/text/button和同步生命周期/点击函数；不导入系统模块、不声明sensor/file等能力、不使用计时器、条件视图或二维码。仍沿用同一JSC/protobuf编译链、逻辑宽度、签名身份与普通安装入口，先隔离“最小包可启动”这条边界。

从模块根运行`node tools/build_startup_probe.cjs`，在本目录dist生成org.imuresearch.s5start.release.0.0.1.rpk。构建自动从父模块复制同一图标、读取本机既有签名与工具链；不需要把私钥放到本目录。

只有表盘和自带菜单已恢复正常时，才由用户通过AstroBox安装并打开一次。预期可见“阶段D2”；点一下按钮后D3、点击次数1，再用手表正常返回操作退出。记下实际阶段与响应，不录制传感器、不反复重开。

判读：若最小页可用，只支持基础页面/脚本/触控在该包上运行，不能证明采集App已修复，更不能立即恢复2秒采集。若仍整表黑屏或卡顿，停止继续装/试其他变体，先保留安装与固件资料、取得普通调试日志后再讨论运行环境。不要据此刷机、降级、修改系统权限或恢复出厂。

D0为默认数据，D1为onInit执行后，D2为onShow执行后，D3为点击处理后。这些只是页面显示的阶段标记，没有设备侧持久诊断日志，不能当崩溃栈或硬件在场证明。19项软件测试/签名检查与真机观察分别留证。
