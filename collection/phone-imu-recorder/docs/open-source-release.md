# 科研采集工具的GitHub发布准备

状态：本地工程和文档准备；未创建公开仓库、推送源码或发布Release。

先保留为主研究仓库的`collection/phone-imu-recorder/`模块，与检查脚本、研究协议和模型按版本关联。APK放GitHub Releases，源码忽略APK、SDK、签名和缓存。当前已有源码、Gradle Wrapper、34项Java/4项Python测试、数据格式、独立检查器和实测限制。

正式发布前完成以下事项：

- 确定作者、机构、导师认可的项目名与许可证；按实际作者生成引用信息，不代填作者或虚构论文DOI。
- 确定发布签名与升级管理。当前调试签名用于本机测试；正式密钥私密保管，签名变化须安排旧记录导出/迁移。
- 用干净检出验证README入口，整理toolchain-lock与历史材料的本机路径；目前Android APK仅在本Windows实际构建过。
- 核对Gradle Wrapper、测试依赖和后续库的许可/来源；运行时没有第三方依赖不等于构建工具无需核对许可。
- 准备明确标为synthetic的可下载示例、检查命令与预期输出。单测已有临时合成夹具，私人会话不作公开示例。
- 截图标版本；完整手机截图可能包含通知标识，公开版本先由用户确认。设计图不冒充实验截图。
- 逐项核对公开文件：家庭点云/IMU、设备序号、完整系统诊断、SSH、代理、签名和账号材料不随源码推送；忽略规则不能代替审查。
- 列实际测试过的机型/版本与失败项，不将单机短试写成广泛兼容。
- 按目标会议的Artifact政策准备复现实验说明，源码/APK/UI不保证论文录用或Artifact徽章。

项目尚无Git首个提交或远端。后续按明确清单逐文件暂存，避免`git add .`带入历史资料。本轮没有发起公共发布。
