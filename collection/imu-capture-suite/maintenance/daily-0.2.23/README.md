# S5 联合采集 0.2.23 / code25

当前手表源码快照，配套 AstroBox 连接插件 0.2.5，手机 0.2.4 保持。历史0.2.19与旧采集器不覆盖。

本版在已保存数据格式与三轴采样接口不变的条件下，修复目录原生API语义、返回按钮兼容和对时作废处理。
对时不成立时保留明确的作废记录并继续采样，不能把作废对时当有效物理时钟。
记录管理采用封口记录快速删除路径，保留最终确认；系统回执不冒充再次读取并确认文件不存在。

0.2.20～0.2.22 使用同一新身份，可保留数据覆盖到0.2.23。0.2.19及更早旧身份不能直接覆盖；先导出全部需保留记录并在电脑核对，再按迁移说明处理。禁止为了升级直接卸载或清数据。

源码测试见 tests/。安装包与去私有路径的SHA清单位于本仓库私有Release，二进制不进入Git树。签名私钥、真实记录和设备日志不上传。
本版本源与安装包已经过电脑侧针对性检查；这不替代蓝牙、原生硬件、长期连续录制或科研同步验收。
