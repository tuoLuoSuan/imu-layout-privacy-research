# IMU 室内布局重建：条件可辨识性研究

从普通手机可读的六轴惯性数据（加速度 + 陀螺，**无磁力计**）重建房间的二维家具布局，并量化
**哪些家具参数被证据确定、哪些仍由先验补全**。

核心主张：决定布局泄露的不是活动时长、路程或观测次数，而是**活动在每件家具自由轴上的几何跨度**；
并且存在**活动不可达的歧义下界**。

## 方法概述

1. **轨迹**：RoNIN 从六轴 IMU 估计二维轨迹（预训练权重，不参与本研究的训练）。
2. **动作**：五类（走 / 坐 / 躺 / 开柜 / 其他）滑窗分类，取动作时段的轨迹位置为锚点。
3. **布局**：把每类动作当成一条几何约束——躺点约束床的位置与朝向、坐点约束椅与桌的墙、
   开柜站位约束柜的墙与法向；走过的区域排除大件占据。
4. **输出**：每件家具给出点估计、候选集与约束它的证据。

## 主要结果

见 [`RESULTS.md`](RESULTS.md)。要点：

- 真实房间端到端（对激光雷达真值）：床 0.122 / 桌 0.056 / 柜 0.050 / 椅 0.194 m
- 15 个三维场景：四件家具全部输出 15/15，床 0.00 m、柜 0.35 m、桌 0.84 m
- 歧义律 `w = L − span` 解析式与实测一致
- 同样 8 次观测：同一把椅子 1.20 m，换 8 个位置 0.28 m（**4.3 倍**）


## 数据与权重

- 原始录音、激光雷达点云与训练权重**不随仓库分发**（体积与隐私原因），可按需索取。
- 三维场景评测使用 AI2-THOR 的 iTHOR 场景，场景清单与导出脚本本地生成，不入库。
