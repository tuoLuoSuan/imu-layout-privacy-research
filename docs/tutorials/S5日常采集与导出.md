# S5 日常采集与导出

2026-10-17。当前已通过的是一条0413/high/通用入口、600044ms的十分钟前台记录。界面日常版手表0415/手机接收025只在电脑准备，沿用这套采集/运输实现。

## 覆盖更新

手表：把 `D:/Download/S5-Recorder-0.4.15-source-9b4eab7b.rpk` 复制手机，在AstroBox原本地入口保留数据覆盖更新IMU采集，不卸载/清数据。

手机插件：把 `D:/Download/IMU-S5-Receiver-0.2.5-055fea6f.abp` 复制手机，在AstroBox插件本地入口覆盖IMU腕部接收。ABP装在手机，不推到手表；如提示重启，只重开AstroBox。

本轮可先交DS审阅，未要求立刻更新。更新后只核首页、旧记录、退出与插件页面；无需为界面更新重录十分钟。若卡住就停止，保留提示。

## 采集一次

1. 手表设置时长和high，通用入口已固定。按既定流程在采集前停止手机AstroBox，保存后再打开接收，减少此前断连/配对弹窗干扰；不解除配对或清数据。
2. 点开始后停在采集页。App自动保亮；不按侧键、切页或退出。到时自动保存，也可手动停止。高档启动明显偏慢时会提前停存并提示，保留这条导出核验，不连续重试覆盖。
3. 看到已保存且录制停止后才重开手机AstroBox；停止后恢复正常息屏。

菜单15/20/30分钟尚不等于实机验收通过。需要超过当前已验十分钟时，应另定条件验证。当前不承诺息屏/后台继续采集。条数/秒表示软件到达速度，不能当硬件采样Hz；与雷达联合测量前仍需确定单位、轴和时间对齐。

## 保存到电脑

手机AstroBox保持S5已连接，插件点准备接收。手表记录页选择已有会话→导出→蓝牙传输；两端停在对应页，App自动保持导出亮屏。手机显示已接收后点保存文件，系统对话框使用默认新文件名存Download，保留原件。USB连接电脑后可取回分析。

记录首次读取可等到30秒，有进度和取消。若目录超时，原记录仍保留；先保留错误原话，不反复点刷新、不删除来猜空间原因。单纯“已保存”不替代电脑CRC/序号/封口和连续性检查。

## 整理记录

记录页点整理记录，可翻页勾选或选本页旧记录，默认保留该列表最新一条。先移回收可恢复，但仍占40会话名额。回收区点整理回收，可批量恢复；永久删除前先确认电脑外部原件已完整核验，再最终确认，无法撤销。

批量按条顺序处理，有进度；取消会完成当前条后停。报错后可能部分条目已完成，余下保留；超时当前条结果可能不确定，需刷新核验。只处理已导出并核验的记录，不把“选旧记录”当自动证明旧记录都有备份。早期记录恢复与备用二维码仍保留。
