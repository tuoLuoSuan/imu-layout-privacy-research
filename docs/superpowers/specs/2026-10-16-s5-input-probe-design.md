# S5 普通输入检查设计

用户要求继续使用现有S5开展科研，授权Codex自主决定实现。按此授权实施，不重复询问功能偏好。当前目标是取得普通接口的运行证据，不能预先承诺固件提供硬件时钟或六轴。

## 选择

采用0.3.4之上的独立0.4.0构建配置，同包同签名，保留旧源、旧包和所有记录。新增“输入检查”，原采集入口不切换。相比直接替换现有入口，这能保留对照；相比另起包名，这能复用已验证的普通传输注册和SAF出口，无需改手机插件。

## 输入和证据

1. 用户主动打开检查页后，仅检查`@system.sensor`方法类型和`DATA_TYPES.ACCELEROMETER`，不订阅其它传感器，不查询账户/位置/设备标识。声明面不等于运行能力。
2. 用户主动点“试采2秒”后，仅尝试一次`subscribe({type:实际ACCELEROMETER值, interval:'high', callback, fail})`。不猜数值、不映射game到high、不自动回退。该形态来自固定公开参考，S5运行兼容性待验。
3. 按固定参考，subscribe返回订阅句柄，unsubscribe接受该返回句柄，而非传感器类型。记录实际返回值；句柄异常即停止候选，不猜清理参数。回调/异常/失败原话有界保存。
4. 最多2秒/128回调/24KiB原始回调JSON，单次最多2KiB；超限明确停止，不裁掉后伪称完整。页面隐藏/销毁停止本候选，不续录。无循环试探/自动重试。
5. 原始回调对象保存为JSON快照，兼容的直接XYZ或ACCELEROMETER.XYZ可派生现有六列行；未识别形状仍保留原始快照，不猜其它嵌套。JSON不能表示的值明确报错，禁止静默变null。
6. 每个回调记录Date.now到达时间；若当前全局确有performance.now，则另存原始读数和可用性，不将其称硬件时钟或手机同步。不合成样本时间/补值/舍入XYZ。返回对象中的时间字段原样保留，语义另核。

## 文件与界面

沿用schema2运输、严格文件名和CRC，head标记`record_purpose:input_probe`、真实接口/档位；tail新增`input_probe`完整诊断。零样本失败也封口，可列出/导出。新分析工具在原核验器之后验证探测字段，分开原始warnings与派生warnings；旧原件和旧报告不修改。

检查页显示声明状态、候选状态、回调数；忙碌时挡住采集/导出。每次启动最多一次候选，不在用户回页时自动重试。普通采集仍为原来的专用接口。修复已证实的传输failed被onHide覆盖为cancelled问题，仅取消正在loading/sending的传输。

## 验证与退出

主智能体测试：声明缺失/getter失败；小数和原始时间字段保留；仅一次订阅及返回句柄清理；同步fail/异常/静默/超预算/隐藏/写失败；真实构建产物、证书/签名/CRC/三项权限/JS源格式；旧源码和原件摘要保持。合成测试不当真机结果。仅用户AstroBox保留数据覆盖安装，先核首页/声明页，再一次短试，原普通手机接收插件0.2.3不改。异常不连续试变体。下一阶段依实际原件决定标定、同步和持续性，不因缺少硬件时间就否定所有窗口级研究，也不冒称样本级同步。
