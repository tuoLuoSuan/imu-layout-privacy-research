## 1. 按上一轮复核修了三处

| 问题 | 修法 |
|---|---|
| 床尾锚点落在床的长侧边（15 个场景里 12 个） | `anchors_true` 改为按**床的长轴**取「头侧贴墙」的对端短边中点：`head_left = x0 <= (W - x1)` / `head_down = z0 <= (L - z1)` |
| 通行惩罚是常数 0.5、接口无轨迹 | `layout_core.solve` 增加 `traj` 参数与 `_pen(tr, boxes)`：**只惩罚 walk 点落在 desk/cab/bed 内**，椅子与躺点允许进入占地；`sim_eval` 新增 `traj_of` 合成 S→椅→柜→床尾→S 的走一遍路径（每段 20 点，全 walk 标注） |
| 桌与柜被迫同墙 | **拆开**：柜墙由「站位离柜面前沿一臂」独立判定，桌墙由「椅子就在桌前」独立判定（DCH 取桌深），两者可不同墙；同墙时仍做沿墙推开 |

附带修了一个真 bug：`build2` 里局部变量 `gap` 覆盖了参数 `gap`，导致所有候选被推出房间、全部返回 no_solution。

## 2. 单墙判定的上界（先说清楚模型能到哪）

| 判定方式 | 正确率（15 场景，真锚点） |
|---|---|
| 柜墙（独立） | **15/15 = 100%** |
| 桌墙（独立，DCH=桌深） | 10/15 = 67% |
| 两者同时正确 | 10/15 = 67% |
| （旧）桌柜共墙联合 | 9/15 = 60% |

桌墙的 67% 是**当前信息的真实上界**：椅子到桌的最近边中位 0.00 m、p90 1.92 m，有些场景的椅子根本不在桌边。权重消融（w_chair 0/0.3/1.0 × σ_chair 0.30/0.60/1.00 × DCH 偏移 0/0.4，共 18 组）**结果全部是 9/15**，说明限制来自结构假设而不是权重。

## 4. 还没解决的问题

1. **桌的 IoU 命中仍是 0%**。中心误差 1.00 m 主要来自沿墙位置：现在把桌子**居中**放在椅子在墙上的投影处，而真实里椅子常坐在桌子一端。这个偏移无信息可以定，除非知道「人坐在桌子中间还是端头」。
2. **柜的 IoU 命中也是 0%**。中心误差只有 0.33 m，但柜子本身很小（场景里中位 0.85 × 0.13 m），0.33 m 的偏移就让 IoU 掉到 0.5 以下。**用 IoU≥0.5 作为小物体的命中判据本身不合理**，应改为「中心误差 ≤ 0.3 m」或「边界误差 ≤ 0.3 m」。
3. **5/15 场景 oracle 都无解**：家具互相重叠或装不进房间的几何约束太硬。
4. **六臂的口径问题**（GPT 上轮指出，尚未修）：chair_only 实际是把 cabinet 锚点设成 seated，不是真正移除；shuffle 有 54/375 仍是原排列；椅子 0 误差是输入回填，应单列。
