# 接触预算固定类别配额后怎么变（034）

## 1 问题

032 把 k 钉在 6，证明配额固定的分散选择比配额固定的随机选择好（12 间确认批 +0.0899；扩到 64 间后 +0.1202，44 好 6 差 14 平，p=1.3e-7）。但 k=6 是个选择，不是测量：为什么是 6，不是 10，不是全部 14？这一条把 k 变成变量。

## 2 设计

同一套冻结的配额规则（最大余额法分配，保证每个有接触的类别至少一个名额），k 取 6、8、10、12、14，三个臂：`bal_disperse`（配额内最远点贪心）、`bal_random`（配额内均匀抽，种子 500000+10·room+s，三个种子）、`plain_random`（不限配额，种子 26000+10·room+s）、`base`（全部接触，只在 k=14 有定义）。

数据来自三处，合并成 76 间：

- `quota_k034`（开发 12 间 11500–11511，k=6…14，全部臂）；
- `quota_k034b`（52 间新房 11712–11763，k=8、10、12，disperse + random）；
- `select032_64` 的两个 stage（64 间 11700–11763 在 k=6，含 base 行）。

随机臂先在房间内取三个种子的均值，再跨房间统计，所以配对差等于两臂均值之差（`budget_curve034.py` 按这个顺序实现）。

k 等于可用接触数时配额臂与随机臂必然相同：实测 k=14 时 76 间全部相同（55/76，F1 0.91197），内部检查通过。

## 4 怎么读

- 预算越紧，落在哪里的选择权越大：k=6 时分散比随机多 14.7 间整屋命中、平均 F1 高 0.109；k=8 还有 +0.045；k=10 只剩 +0.010 且不再显著；k=12 反号（−0.017，p=0.21），k=14 两者按构造相同。
- 单调性说明这不是抽样噪声：四个点在 76 间房上按顺序递减，唯一的反号点在预算已经用掉六分之五的地方。
- 与 032 的 k=6 结果一致（64 间 +0.1202），合并 76 间后是 +0.1092，说明 12 间那批的低估值是功效问题，不是效应消失。
- 这条曲线也解释了 033 为什么要在「分散 / 重复」上做对照：预算用满时选哪几个已经不重要，重要的是这 14 个接触落在多少张不同的面上。

## 5 边界

- 单解码器（`priorcost014` 的 `base`，cap 128）、单落点协议（分散，14 次访次）、严重度 0、`prefix` 噪声。
- 配额规则保证每类至少一个名额，所以 k 小于类别数时会退化，本文没有测 k<6。
- 整屋命中，不是逐实例精度；非 ok 行按惯例记 0 分保留。
- k=6 的 12 间开发房与 64 间新房来自不同运行批次（前者 `quota_k034`，后者 `select032_64`），两批协议一致但批次不同。

## 6 复现

```
python -m analysis.layout.quota_k034 --rooms 11500-11511,11700-11711 \
  --k 6,8,10,12,14 --jobs 3 --out output/layout-recon/quota_k034
python -m analysis.layout.quota_k034 --rooms 11712-11763 --k 8,10,12 \
  --arms bal_disperse,bal_random --jobs 3 --out output/layout-recon/quota_k034b
python -m analysis.layout.budget_curve034
```

产物：`output/layout-recon/budget_curve034.json`（逐 k 的命中、F1、配对差、区间、符号翻转）、`quota_k034/paired_stats.json`（24 间第一遍）、逐房间 `rooms/room-*.json`。
