# 011 原始双设备输入修复方案

用户授权继续修复，不增加真人采集、不换手机/表权重、不删除旧证据、不调用子代理。本轮不先写论文。

1. 保留010和DS全部冻结结果。核对实际前端、位姿坐标规范、姿态插值及经验精度推论。三点oracle混合不是0.1m必要条件证明。
2. 只用历史原生房0–19的合成开发流训练新的段位移模型；速度0.45/0.65/0.85m/s，物体真值仅用于规划和训练位移标签。推理特征只含原始六轴、信号估计姿态/零速段和段时长，不含绝对位置、实例、房间ID、脚本标签或真姿态。
3. 在旧8间开发长记录选定前端；DS已反复查看的16间仅诊断，不能再冒称全新确认。冻结后在11100–11131的32条新长记录确认；若部分几何曾用于短链，明确仅新长录音而非整个几何从未见过。
4. 同一手机活动RF＋同一腕部柜门RF，柜标签只从手表进入；新旧前端使用同一cap128解码器与接触/通行界。比较真姿态+相同预测动作、原始旧前端、新前端，分开报可行性、全屋中心0.5m、F1与IoU。
5. 验收不预设百分百：先检查原始输入与oracle的差距、轨迹误差和失败分账；如果只是同生成族监督模型有效，不能外推为真实自然活动泛化或RoNIN被修好。
6. 真实房原始重放及010默认入口必须保持；输出完整DS说明、代码、派生源表和失败证据。只提交本轮显式文件，16项二进制固定摘要保持。

执行补记：在旧8条上选定标量频谱位移、四向规则化、未知坐点/柜面回访；加手机测得方向和0.3接触残差代价，新旧前端同用一套新解码器。新32条确认后不再调模型。得到17/32而非80%目标；完整数值、失败分账、坐标规范纠正、隔离重跑与真实生产链回归写入011审核稿。图按实测比例，不生成尚未测量的IMU阈值曲面。解析步态逆拟合只是未选原型，不能冒充独立成功。
