# S5 0.4.3 自动保亮首次验证

本机测试/构建不代表S5支持新增brightness方法。普通入口、同包同证书、源格式；不改配对/固件/系统超时，不卸载或清数据，所有10条原件保留。

1. 保留数据覆盖更新后，只打开一次，确认0.4.3首页及退出正常，不开始录制。若黑屏卡住即停止，不重复打开或自动发另一变体。
2. 启动通过后，只录一条10秒/high/通用入口，手腕放稳、不触屏保亮、不切页；如出现“保亮接口不可用/保亮请求失败”则未开始，保留原文，不重试。观察是否自动到期保存，报告计数、全程亮屏/是否触屏/原提示；保存后继续不碰，观察是否恢复自然熄屏。
3. 只导出这一条，经手机0.2.3完整接收并系统保存到Download，普通USB取回。核CRC/清单/行/封口、screen_policy/acquire/release、原传感器取消及连续性字段；success仅为接口观察，亮屏仍要用户报告。
4. 通过后另做一次60秒全程不触屏同设置，检查超过旧9.5秒息屏点后是否保持页面、到达节奏/心跳/封口及释放仍正常。原件核验后才单独安排5分钟。

不因计数接近166/1000而判通过，不删告警或补点；自然息屏/后台、单位轴向、硬件Hz与同步仍不由该前台协议证明。
