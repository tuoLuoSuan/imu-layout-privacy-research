# 阶段1：整会话手机＋腕部配对增量的前瞻协议

版本1，2026-10-23。本地协议冻结；不是第三方注册或可信时间戳。尚无新的校准/正式测试数据，模型参数尚未封存，**本文件不是立即开始64条录制的卡**。第一次需要用户时只给最小开发任务。

## 1. 两阶段与主张边界

**阶段1只检验当前一个人、一个房间、固定携带方式下的预测信息增量。** 同一批整会话输入到全部管线，不要求先有多布局。第一主查询明确固定为：

> 这一整段任务是否发生戴表手真实开合柜门，而不是同位置、相近幅度和节奏的空做？

R=1、P=0。一次会话只提供一个真标签和一个预测概率。它是敏感交互行为的机制查询，**不是“柜门在哪”或未知布局查询**。空间位置先保持相同，以免模型只凭手机路线猜条件。不能换成“手臂动了没”来救分类。

**阶段2另检验空间关联及外推**：在可靠事件↔地点关联和独立区域参考后，再测交互区域/布局候选，在未见布局与人上评价。阶段2场地不是阶段1前置；阶段1成立也不自动成立空间增量。点云/几何电脑工作可以并行。

已有v3三条为开发诊断：301个是访问顺序假设，非301个布局。旧三条、旧B四包全部不进入前瞻留出，不追认formal_score。

## 2. 主终点、意义阈值与判定

每会话对每管线输出 `p(R)`，Brier损失为 `(p-y)^2`。常数先验0.5的损失为0.25。先计算每会话 `d = loss(phone) − loss(joint)`；正值代表联合更好。

每个预定录制块含一条R和一条P，块差为两条d的平均。主估计是各块等权的平均差 `Δ`。固定：

- **最小有意义增量 MIE = 0.05 Brier**，相当于相对0.25无信息基线的20%损失幅度；这是本单元事前选择的工程意义线，不宣称公认隐私阈值。
- 主零假设 `H0: Δ ≤ 0.05`，单侧α=0.05；用块差的t区间，检验独立、近似正态块均值的模型。报告全部块值，不以正态性检验结果改主方法。
- 主规则：32个完整块的单侧95%下界必须 **>0.05**。这才支持“超过预定有意义线”。单纯点估计≥0.05或p<0.05对零，不够。
- 若要进一步称“超出重复信息/额外随机特征”，joint相对shadow和noise的块差单侧95%下界也都要>0。这是所有条件同时成立的交并检验；不把单项显著挑出来写全套通过。
- `watch-only`、常数先验、各条件硬判别/弃权和accuracy差均报告。joint≈watch-only时不称融合协同；手机本已全对属于天花板。
- 未过门：下界未越线是“尚未建立”；若上界<0.05，可在本条件与模型假设下排除该有意义增量。不得说所有腕部方法无效。

Brier是实际预测的适当评分，不要求把模型概率先当真实后验；仍须报告校准图/真值分数。ΔH不作为阶段1通过门。

## 3. 分析单元与功效：现在定清楚

**特征/标签单元是会话；统计推断单元是预定录制块。** 一块一条R、一条P，顺序独立随机，跨设备不拆窗配标签。正式块分布在不同自然日，同一天的两个会话不假装两个独立日；跨日独立仍是需要披露的条件假设，不因日期不同就被证明。

规划上限情景为：8个模型校准块（16会话），8个独立方差规划块（16会话），正式32个块（64会话），共96会话。三组日期/会话不重叠。先只安排最小开发对，不一次启动96条。正式块中每个会话只出一行特征，任何窗口/seed/噪声副本不增加n。

独立近似正态块模型的非中心t计算如下。检验H0=0.05，设计备择Δ=0.10，二者差0.05：

| 块差SD | 正式块数 | 正式会话数 | 主检验功效 | 相对0.05零假设，80%功效可检出的总Δ下限 |
|---|---:|---:|---:|---:|
| 0.05 | 32 | 64 | 约99.99% | 约0.0725 |
| 0.075 | 32 | 64 | 97.94% | 约0.0837 |
| 0.10 | 32 | 64 | 86.89% | 约0.0949 |
| 0.15 | 32 | 64 | 57.90% | 约0.1174 |
| 0.20 | 32 | 64 | 39.68% | 约0.1399 |

这里的86.89%**不是在真实Δ恰为MIE=0.05时获得支持的概率**，也不是三项联合门的功效。真值在零假设边界时拒绝率至多α。辅助对照差的方差/相关性还未知，不给全套归因门捏造80%保证。

采正式前，先在模型校准16会话拟合并冻结，**用另外8个未参与拟合的方差规划块**计算块差SD的单侧90%上界 `sqrt(7*s²/chi2.ppf(0.10,7))`。这依赖独立正态块差的规划模型；不拿共享训练集的留一预测当8份独立方差证据，不拿训练误差作规划真值。方差规划后不重训模型。若上界>0.10、明显时间趋势或块依赖，**这个64会话方案不以“功效足够”放行**；先改研究设计/估计精度或只做探索，不把采完后增加到显著作为方案。没有新校准/规划数据，今天不能声称该条件已满足。

硬判别若另用独立会话McNemar检验，仅是计划对照：检测20个百分点、80%功效，discordance为0.2/0.4/0.6/1.0时，所算最小n分别为33/67/99/158（α0.05单侧；离散功效有台阶）。这些独立会话数**不能套到存在日内聚类的64会话上**。3条即使全改善最小单侧p=0.125，不存在“3/3显著增量”。

计算：[block-power.json](D:/Project/imu环境重建/docs/reviews/evidence/2026-10-23-publish-and-paired-stage/block-power.json)、[paired-power.json](D:/Project/imu环境重建/docs/reviews/evidence/2026-10-23-publish-and-paired-stage/paired-power.json)。这些是功效模型，不是真实效应。

## 4. 两个真正无新增信息的对照，与另外两种压力对照

“零信息”必须说明是**给定完整手机输入后的新增信息为零**，不是对照的所有信息都为零。

| 组 | 固定构造 | 能回答什么 |
|---|---|---|
| P | 手机acc＋gyro，8维固定统计 | 主基线 |
| W | 腕部acc，4维固定统计 | 腕部单端；不能省 |
| J | P＋真实W，12维 | 待检增量 |
| **shadow空对照** | `P + T(P_acc)`；T为确定的6Hz因果EMA后本端16Hz表征，提取同4维模长统计 | `I(Y;T(P)|P)=0`；查增益是否能由手机信息的另一表征/更宽模型获得 |
| **noise空对照** | P＋由预先固定seed及不含条件的随机ID生成的4维独立高斯特征，12维 | 新特征本身与标签/原件无关，查额外维数/随机过拟合；不冒充物理腕部噪声模型 |
| 规格消融 | 手机降成三轴/16Hz后单独比较 | 测规格与身体放置差异；它自身仍含活动信息，不能叫无信息流 |
| 异人腕部压力对照 | 获准的另一人、独立会话，按phone-only活动层/采前任务分布固定匹配，不按测试真标签挑最好流 | 查对人的依赖/移植性；包含活动信息及分布变化，不是条件独立零假设 |

本方案用模长统计，旋转到估计重力方向不会改变模长；因此shadow不伪称世界三轴已标定。EMA用于规格表征，不等同理想砖墙抗混叠或真实手表物理带宽。完整手机6轴基线保留，不能先删陀螺再称强phone-only。

反例足以否定“异人同活动=零”：手机不含标签时，若按真实类别给每条换入同类别、可完美分类的他人腕部流，即使没有任何真实个体绑定，也能全部猜对。即使不按R/P答案匹配，活动水平也可能与目标相关，换人本身不能保证条件独立。不能把它当个人绑定或物理同步证明。

现有资料没有第二人独立腕部池；不造这个对照。不阻塞先算P/J的条件化增量，但在完成它之前，**个体绑定结论仍不可判**。即使完成，也不单凭掉分建立因果/物理绑定。

## 5. 固定特征与模型配方

代码：[analysis/paired_session/core.py](D:/Project/imu环境重建/analysis/paired_session/core.py)。当前只用合成输入检查，没有用真实标签训练。

三个本端各4项：时间加权模长variation、90−10分位spread、0.25秒模长差RMS及95分位。加速度以本会话平均模长归一化；手机gyro保留已知单位尺度。不把表中未知单位当m/s²，不估世界朝向。滞后计算只在本端、有支持区间上进行；不是把16Hz变成100Hz物理信号。

标准化均值/SD只从校准16会话求；常量维scale=1。固定L2逻辑回归：平均logloss＋`||β||²/2`，截距不惩罚，Newton最多100步、步长收敛1e-8、固定数值稳定项1e-8；所有变体同规则。概率夹到[1e-6,1−1e-6]。没有超参搜索、轴挑选、窗口挑选、XGBoost或深度网络。

噪声seed为`paired-session-null-v1-20261023`，用无条件随机ID的SHA派生PCG64；ID须在条件指定前生成或来自不含条件的原始UUID，不能用R/P文件名当ID。不以多次噪声生成扩大样本数。

8个模型校准块只拟合最终参数，封存后才预测另外8个方差规划块。方差规划结果用于事前设计可行性，不算正式测试，不在之后重训。代码中的14行留块拟合仅供合成/开发敏感性，不用于正式方差门。若修改配方、特征、质量门或候选查询，先升协议版本，已见材料永久留开发，不读正式分数后改。

## 6. 数据来源、标签与硬件科学范围

- 旧v3三条和旧B四包只作开发/稳健性诊断；旧B时长不配平、旧D门失败不追认。旧数据与新校准、新正式按ZIP SHA与native/session ID去重。
- 新R/P同站位、同手机口袋、同戴表手、相近轨迹与幅度；听同一个30秒共用引导。一条60秒档只做一遍30秒任务，保留启动/收尾余量；不是两遍30秒＋前后20秒硬塞进60秒。
- 视频-only确认真实接触/柜门运动或空做、完整条件、有无中断/混入其他活动。无法看清为unknown，不凭IMU或模型分数补标签。单人知道提示脚本的非盲限制披露。
- 会话共同覆盖采用“先两端启动→任务→停止”的视频/参与者声明与有效原件支持；不读表屏数字，`strict_common_task_coverage_proven=false`、`physical_clock_accepted=false`。只支持条件化会话关联。
- 独立软件质量门沿用新单元候选：100–250ms短gap软标记，保留有效点；>250ms、时间/数值无效、身份/传输/封口失败为硬失败，含首尾空洞。它是当前支持规则，不是物理缺失率或跨端同步证明。
- 正式目标32完整块，最多尝试36块。替代仅限先于预测解封判定的技术/参考不完整，不看分数；取时间顺序前32完整块，全部失败尝试/原因另报。仍不足32则主分析不完整/不可判，不为结果加录。旧批次不补录的历史合同不变。

**S5固定当前三轴加速度、约16Hz观察回调、无陀螺。** 这是本单元输入限制与外推范围，写入协议，不把约16Hz当物理恒定采样或一般腕部信息上界。更好的六轴/更高频设备以后属于新单元，不混进本批替换。0.2.19日常软件冻结，手机/插件保持。
