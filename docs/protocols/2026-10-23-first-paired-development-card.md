# 第一次配对开发：只做两条，做完就停

这是当前一个人/房间的机制开发，不是正式留出，也不是布局实验。不补旧批次，不换手机/插件/手表包，不用拍触点、举屏或读样本数。若现在不方便，可留到方便时再做。

## 准备一次

- 沿用刚才已确认可正常使用的日常软件。手机固定同一个裤袋，手表固定同一手腕，两条都站在同一扇柜门前。
- 电脑相机能看清戴表手、柜门和你的动作即可；这次不要求全房间、脚部路线或A/M/C标记。
- 使用同一份[共同节奏音频](D:/Project/imu环境重建/output/joint-privacy/paired-stage1-20261023/common-guide-40s.wav)：总40秒，开头8秒安静准备，中间30秒提示5次动作，结尾2秒余量。耳机听也可以，视频不需要录到音轨；它不是同步码。
- 每轮提示“伸手→动作→返回→静候”。“动作”时做一次轻开再合，或相近的空手往返；不用再自己数6次。

## 第1条：R，真实开合

1. 相机先录像；插件准备，手机开始，再在表上开始 **1分钟**。
2. 两端已开始后，尽快播放一次共同音频；开头8秒回到柜门前站稳。
3. 戴表手按提示轻轻开合柜门，共5次；每轮“动作”的两秒内轻开、轻合，“返回”时手回原处，静候时站稳。不赶、不用力制造冲击。
4. 音频结束后继续安静站着，等表保存/回传和手机保存完成，再停相机、导出整包。

## 第2条：P，同位置空做

按同样启动、音频、结束和导出顺序，再做一条1分钟。

柜门保持关闭。戴表手在同一位置，尽量沿第1条相近的幅度/路径做开合往返，**不碰门、不真的开门**；其余站位、手机位置、节奏与等待相同。不是只做一下伸手就提前站着等。

## 做完

保留两个整包ZIP、两段原视频，保持原文件名，导出后告诉我“R→P都导出了”。我核身份、动作匹配、会话关联与原件质量，再给两条的描述性特征差；一对记录不会被写成模型准确率、显著性或腕部增益通过。

任何报错、自动提前结束、动作来不及完成，就停下保留现有材料，不重录救分；第1条失败先不做第2条。不用删记录。你不需要标秒、改JSON或操作分析工具。
