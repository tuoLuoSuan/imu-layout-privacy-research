# 0.4.2 连续性观察首次真机协议

先决：旧0.4.1三档10秒原件保留，手机接收插件0.2.3不变。0.4.2仅本机软件验证通过，设备启动、连续性字段及运行开销待验。不得把60秒合成结果当真机验收。

1. 通过原AstroBox入口保留数据覆盖更新，不卸载、不清数据。只打开一次，确认v0.4.2、首页high与通用入口、能正常退出；先不录制。若卡住立即停止，不反复打开。
2. 启动反馈正常后才做一次10秒high/通用入口前台静置，保持采集页亮屏。不做姿态动作、不切页或按侧键；如需保亮，触碰情况补记。结束后反馈已记录/已保存数及原文告警，不重录覆盖。
3. 手机0.2.3准备接收，手表选该条仅传一次；手机系统保存完整TXT到Download，用默认新名，USB取回。旧七条保留。
4. 取回前后/电脑SHA相同，原schema2 CRC/清单/行序号/封口通过；新分析器核head.sensor_path、策略、心跳事件与tail摘要、接纳观察、首末JSON、全部大间隔及开始/结束空窗。亮屏为用户报告，非外部电源状态测量。
5. 新增字段实证通过后，再另定high档60秒全静止前台基线；姿态/单位检查另做固定方向和明确边界的短矩阵，不与一次长录混成唯一验收。运动转换段不套静态重力阈值，不预设±3%/5%就叫标定通过。

本协议不主动调用getRecentData：公开参考实现是无返回取消句柄的一次性订阅，回调包装data/dataType，非历史数组；本机typeof function不证明其行为/清理。当前无硬件时间、单位/轴向标定、batch完整性、息屏、分钟、六轴或同步结论。CRC不作认证，人工系统保存不等于无需用户协助的自动外传。
