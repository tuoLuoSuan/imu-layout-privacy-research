# S5 0.3.0 分级验收（尚未执行）

适用 S5 标准版／用户报告固件3.102.036；普通 AstroBox 安装，无 root／固件改变／特权插件。Codex只完成本机软件检查，尚未操作这版真机。

1. **升级前**：先在已装0.1.1导出原来的2秒会话；拍齐原协议所有页，取得原件并独立核验，保留旧RPK与源文件。不卸载旧应用，不恢复出厂。
2. 使用本轮最终核验的0.3.0候选，通过原AstroBox普通入口同签名更新；不得误选带样式警告的早期构建。仅打开首页检查按钮/字体/图标/退出。整表黑屏卡住立即停止，不反复变体试装，不称根因已修复。
3. **2秒前台静止**：默认game，腕侧按实际选；记录匿名测试编号即可。开始后检查计数与“已保存”增长，自动停止后查看封口状态与告警，按段导出（每段各自页码，先拍完再下一段）。这版不直接跳到5分钟。
4. 原件解码要能获得完整清单、head、全部连续块和tail；核XYZ原值、序号、条数、事件、实际回调率；报告不能以请求档位代替实测。若缺页补拍同会话，不重录掩盖。
5. **管理验证**：用专门短测试记录核移入回收区／恢复。永久删除只针对已完成电脑备份的测试记录，核二次确认；真实研究记录保留。App显示“已封口”不等于电脑已备份。
6. 2秒通过后，依次30秒→60秒前台，逐条独立核验后才做更长。不同档位单独测，保持其他条件相同；game不保证约50Hz，也不保证各阶段不变。
7. 息屏／切出另设短对照与外部计时，只改变一个条件，备注每次动作、实际可见屏幕/充电/腕侧。`page_hide`不当锁屏证据。若需系统日志只使用已有普通入口，获取不到则保留机制未知。
8. 分钟级QR可能数千页，正式长录之前优先完成普通消息接收端的低成本可行性检查。当前没有已运行蓝牙文件传输，不安排用户先录半小时。

停止条件：整表卡住／重复写盘失败／write_timeout／queue_overflow／无法恢复已存块／无法导出。保留失败与原件，返回定位，不通过降低判据或特权路径“救数据”。即使本版三轴工程门通过，原始六轴及腕部对空间结果的贡献仍未通过研究门。
