# v3 固定本端窗口开发方法与执行计划

2026-10-23。响应用户“把启动那段去掉”及DS“先产出盘上phone-only基线”的请求。本次全部是已有、已经看过的开发材料，不能称前瞻留出或恢复旧批正式资格。v1/v2及其SHA、旧结果均保留，不覆盖。

## 设计选择

主开发口径固定为各设备自身**记录开始**后的半开窗口 `[20,55)` 秒；对照为不裁的完整会话。采用DS提出的20–55s例子，不扫描窗口、不按分数选边界。设备开始来自phone metadata的collection_start_elapsed_ns及watch封口start_ms；不是第一条样本，亦不是视频PTS或两设备的共同零点。它不保证包含全部五次动作，不证明两端同时发生同一事件。视频约30s节奏、动作路径/接触差异和覆盖局限原样披露。

只在支持该窗口、时间/数值有效、三流运输封口完整及原始全记录无>250ms硬gap时计算本次新开发统计。旧B曾因动作不配平、旧D 100ms失败而未验收的结论不变；不追认旧质量门。本次只用旧B的R/P两条作历史开发训练素材，其动作持续时间差异仍是混杂。

另外两个可选方向暂不执行：按视频/动作峰逐条挑边界会使用参考并依赖更强关联；直接更换四类任务在本机没有四类独立标签，无法立即给新任务模型分数。当前先回答固定口径会怎样。

## 数字怎么来

仅取已明确R/P语义的两对四条：2026-10-22 B的第1/2条，与2026-10-23的R/P。旧三条访问路线不混进活动分类，旧D/W不充当R/P。

**主开发预测：旧一对R/P拟合，隔日新一对R/P预测。** 同时完整报告逆向留对（新对拟合、旧对预测）敏感性；两方向各2条预测， pooled仅4个开发预测、2个日期块，不当4个独立测试实验。新对标签虽不进入拟合，但执行方此前已知道标签、看过数据，故仍不是未见测试集。

每会话一行。复用v1的模长四统计与phone8/watch4/shadow4特征、λ=1 L2逻辑回归、训练集内标准化、Newton最多100步与既有seed。不搜索特征、λ、窗口或最优seed；并列phone、watch、joint、phone_shadow、phone_noise和单独的常数先验0.5。

由于只有两条训练数据，**这是独立命名的微型开发模型，不调用或放宽v1 `fit()` 的16条正式拟合入口**。数学配方相同，训练数量/参考与用途不同。它只说明这一个开发管线能否从这两条历史素材转到另一对；可能极不稳定。v2“不为凑天花板临时训练旧B”的正式限制仍生效：本次拟合数字不填正式天花板，不冒充校准模型，不证明随机水平或腕部增量。

输出 `development_phone_only_brier` 为实际异会话预测 `(p-y)^2` 的均值；逐条概率及损失必须保留。正式 `phone_only_brier=null`、ceiling unknown、`formal_score=null`、`layout_separation=null`、`physical_clock_accepted=false`。即使开发损失<0.10也不自动宣布正式天花板通过/失败；独立校准和规划材料的合同另存。

## 核DS快速判断

仅作为描述核查，计算新对phone在自身记录10–70s的30个2s窗模长CV及gyro模长std；用各整会话平均加速度模长作统一分母，和按各窗均值的CV并列。watch自身12–42s的模长去均值后，在16Hz数值网格上报告6s自相关与2–10s最大正自相关的滞后。窗口、滞后搜索范围只用于核对DS周期描述，不输入分类器，不成为新的动作标签。

“phone低幅波动”不等于条件信息为零；“watch两条同幅/同节奏”不证明全部三轴时域/频域特征不可分，更不证明硬件能力上限。当前方法只用模长，也不能代表全部三轴方向信息。

若将来改四类，标准多类Brier `sum_k(p_k-y_k)^2` 的均匀先验为0.75；除以K时为0.1875。指定一类vs其余、均衡四类的先验二元Brier也是0.1875。必须重定主查询、评分约定、MIE和功效，不沿用二元0.25作保证。

## 执行计划与防护

1. 先保存本方法、四原件SHA和冻结旧代码摘要；再读取本次固定窗口特征。不声称这份方法早于数据采集。
2. 先写红测：真实记录起点/半开端点、短支持/空洞拒绝、训练/预测身份互斥、预测输入不可含标签、标准化不看测试集、训练未来行不得影响参数、二元/多类先验口径。
3. 新增独立 `analysis/fixed_window_dev/`，不改生产采集器、v1分析与旧证据。通过测试后只读原件，封存模型和预测，再交评分器读取既有标签。封存顺序是本地流程，不冒称盲法或可信时间戳。
4. 整段与20–55并列输出所有变体/两个方向，给方法SHA、模型SHA、预测SHA、逐会话损失、限制及DS交接。重算全部旧数据SHA，不删、不安装、不新采，不发卡。
