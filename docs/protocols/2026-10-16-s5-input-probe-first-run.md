# S5 0.4.0输入检查首次真机步骤

本候选依据用户坚持使用S5及自主实施授权准备，Codex负责判断和整合，DS023已核对。仅用户经现有AstroBox入口操作，不卸载/清数据/改配对，不新开训练/其它传感器。

1. 保留数据覆盖0.4.0/code9，同包同签名；手机插件仍0.2.3。先只核首页/退出正常。
2. 主动点首页“输入检查”，回报声明页：方法类型、ACCEL常量值、是否“已声明”。此步无订阅。页面异常/整表卡住立即停止，不反复开或尝试变体。
3. 经当前反馈确认后，只点一次“试采2秒”（无完整声明时只保存检查结果）。手腕静止放稳、保持此页；不自动换接口、补录或延长。原生阻塞超出JS定时器控制时停止操作并保留观察，不能称安全返回。
4. 检查完成后返回“记录”，选择“输入检查”最新项，沿已验手机准备接收→手表一次传输→SAF保存TXT→普通USB取回。即使0行/报错，仍导出诊断，不重录覆盖。
5. 原核验器和附加analyze_input_export交叉核CRC/清单/序号/封口、原始JSON与XYZ/到达时间映射，手机电脑SHA一致。单位/轴向、时间字段语义、native批量保留不由这一步代替。

若实际取得小数XYZ：准备独立候选接入正式记录，再做六面静置/缓慢转动、两种接口短对照、严格前台/息屏与分钟测试。若该入口不可用：先据错误和声明定位可用普通路径或受支持扩展环境；不能把参考源码、两次失败或typeof当作整个S5能力定论。任何特权/固件路线必须另列威胁模型，不能回填普通应用结果。

无硬件时间时仍可评估窗口级特征/对齐需求和不确定性，不制造等间隔样本或宣称样本级同步。最终科研可用性以实际信息和任务证据决定，不能在本机测试后预报。
